Frequently Asked Questions

Do I need an internet connection to process sales?

No. Puxbay POS is built with an offline-first architecture using IndexedDB. You can process sales, scan barcodes, and print receipts completely offline. Data synchronizes automatically once the connection is restored.

Which hardware is supported?

Puxbay is web-based and runs on iPads, Android tablets, Windows PCs, and Macs. It supports standard ESC/POS printers, standard USB/Bluetooth barcode scanners, and standard cash drawers.

Can I manage multiple registers per store?

Yes, you can run unlimited concurrent registers per location. Inventory deductions and sales analytics are consolidated in real-time across all active registers.
